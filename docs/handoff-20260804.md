## Four bugs found by accident, all live for a long time

1. **ESPN 403s a polite User-Agent.** `dvr-dashboard` and
   `dvr-power-reminder` both sent an identifying UA; ESPN serves `curl/*` and
   Python's default urllib UA but refuses `dvr-dashboard/1.0`, any Mozilla
   string, and Wget. Both swallowed the exception, so the dashboard showed *no
   games* and the reminder concluded *"nothing outside the window"* every
   night. Two scripts, same cause. **Check this first if a third ever fetches
   from ESPN.**
2. **`icon-host` rejected filenames containing two dots** — a substring `".."`
   test rather than a path-component one.
3. **`icon-host` sent `max-age=86400`**, so 113 channels served pre-fix logos
   through a *complete* clear-and-refresh.
4. **Jellyfin caches the tuner channel list**, and a guide refresh does not
   invalidate it — the fourth cache between a lineup change and the screen.
